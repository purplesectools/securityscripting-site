This is not a payload library with a nicer UI. It is an attack loop with memory, goal tracking, scoring, leak detection, and tactical drift. Attack modes Choose how much of the run is guided by models versus curated probes. Library Deterministic baselines Use a curated payload family when you want repeatable probes, fast regression testing, or a known security checklist. Hybrid Best of both worlds Blend library-backed probes with live attacker reasoning so the run starts grounded and then adapts when the target resists. Pure LLM Maximum creativity Let the attacker synthesize payloads end-to-end when you want broader exploration, emergent tactics, and novel prompt chains. Model and target support Local-first when you want control, external APIs when you want stronger reasoning. Local Ollama attacker and judge Keep adversarial payload generation and judging on your machine for privacy, reproducibility, and better tolerance for offensive red-team phrasing. External OpenAI-compatible APIs Swap in hosted attacker models through compatible endpoints when you want stronger reasoning, broader model choice, or team-wide infrastructure. Bring-any-target request flow Test direct inference APIs, internal gateways, custom chat apps, RAG systems, and other HTTP-based LLM applications by sending the real request shape they already use.
