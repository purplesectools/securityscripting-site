Why AI vs AI Exists

Many prompt injection tools still depend heavily on static payload catalogs and one-shot jailbreak attempts. Modern LLM defenses adapt dynamically. Refusals shift. Partial leaks emerge before direct compromise. AI vs AI was built around adaptive adversarial evolution instead of static replay.

⬡

Closed-loop evolution

Payloads continuously mutate based on previous failures, behavioral drift, side leaks, and judge observations.

◎

Goal-aware judge

The judge tracks whether the target is gradually moving closer to the attack objective instead of using simplistic success/failure logic.

◈

Hybrid attack engine

Combines deterministic strategy libraries with LLM-driven reasoning and mutation-based exploration.

⌁

Behavioral side leaks

Tracks moderation hints, hidden workflows, refusal weakening, reasoning traces, and indirect information exposure.

The Adaptive Attack Loop

01Define Goal

Provide an objective such as prompt extraction, policy bypass, hidden workflow discovery, or behavioral manipulation.

02Attack Evolution

The attacker generates payloads, observes responses, and mutates strategy families dynamically.

03Judge Analysis

The judge scores leakage progression, behavioral drift, moderation changes, and extraction quality.

04Strategy Pivoting

When progress plateaus, the orchestrator pivots toward alternate attack chains automatically.

Just paste your Burp request.

AI vs AI works with generic HTTP workflows. Copy a request directly from Burp Suite, cURL, browser devtools, or API logs and paste it into the interface. The framework automatically parses headers, cookies, JSON bodies, auth locations, and prompt insertion points.
