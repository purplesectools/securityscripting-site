AI Threat Model Assistant

A deterministic AI / ML threat modeling platform designed for modern AI systems including LLMs, RAG pipelines, multimodal systems, traditional ML, MCP ecosystems, and autonomous agents. Instead of generating vague AI-generated summaries, the engine correlates architectural gaps, missing controls, runtime behaviors, and governance weaknesses into structured findings, attack paths, and chained risks.

Built for More Than Just LLMs

Most AI security tools focus exclusively on prompt injection. This platform models security posture across the broader AI ecosystem including classical ML, RAG, multimodal pipelines, agentic systems, model supply chains, and MCP architectures.

LLM & Generative AI

Prompt injection, output handling, hallucination controls, system-prompt protection, guardrails, moderation, jailbreak exposure, and downstream abuse paths.

RAG & Vector Databases

Retrieval poisoning, retrieval-access control, vector isolation, content filtering, embedding abuse, and indirect prompt injection risks.

Traditional ML

Model extraction, drift manipulation, adversarial examples, poisoning, inference abuse, feature tampering, and weak monitoring coverage.

Agentic AI

Tool misuse, autonomous execution risks, memory abuse, multi-agent trust failures, browser-use agents, and agent takeover chains.

MCP & Tool Ecosystems

Third-party MCP server trust, schema integrity, privilege propagation, lateral movement, and unsafe tool integrations.

Compliance & Governance

Maps findings to OWASP, MITRE ATLAS, NIST AI RMF, ISO 27001, SOC2, GDPR, HIPAA, PCI DSS, and EU AI Act exposure.

Coverage Matrix

Architecture-aware Coverage Engine

Questions dynamically change based on the AI system type selected. Classical ML, LLM, Agentic AI, MCP, and RAG systems each unlock different security and governance workflows.

Data & Runtime Modeling

Models training-data sensitivity, runtime exposure, downstream integrations, sensitive-data processing, governance controls, and user interaction flows.

Agentic AI & Runtime Threat Modeling

The platform contains dedicated coverage for autonomous AI systems, browser-use agents, memory-enabled workflows, code-execution agents, and multi-agent ecosystems.

LLM Runtime Controls

Evaluates prompt strategy, guardrails, hallucination protections, moderation layers, system-prompt exposure, and unsafe runtime behavior.

Agentic & Autonomous Systems

Dedicated assessment coverage for memory controls, tool access, code execution, multi-agent trust, runtime kill switches, browser-use agents, and autonomous workflows.

Deterministic Attack Chains

Findings are not generated through probabilistic AI text generation. The engine correlates weak controls and architecture patterns into deterministic attack chains and graph-based escalation paths.

Multi-step Chained Findings

Multiple weak controls combine into larger systemic risks. The platform identifies escalation paths instead of treating every issue as isolated.

Attack Path Deep Dive

Each chain explains why it fires, which controls are missing, how the attack progresses, and which mitigations break the chain.

Executive Reporting & Risk Prioritization

Executive Summary Dashboard

Summarizes top risks, regulatory exposure, quick wins, severity distribution, and attack-path visibility for leadership and AppSec teams.

Prioritized Risk Decisions

Highlights the highest-priority findings using likelihood, impact, confidence, exploitability, and chained-risk context.

Detailed Threat Analysis

Includes attack paths, abuse cases, mitigations, compliance impact, MITRE mappings, OWASP categories, and quick remediation guidance.

Framework & Compliance Mapping

Maps findings against OWASP LLM Top 10, OWASP ML Top 10, OWASP Agentic AI, MITRE ATLAS, NIST AI RMF, SOC2, ISO27001, GDPR, HIPAA, and EU AI Act.

Why This Project Exists

AI adoption exploded faster than AI security maturity. Many teams now deploy copilots, agents, RAG systems, browser-use agents, autonomous workflows, and ML pipelines without structured threat modeling. Traditional AppSec questionnaires often fail to model runtime AI behavior, prompt attack surfaces, autonomous actions, retrieval poisoning, model misuse, and chained AI-specific abuse paths. This project attempts to bridge that gap with a practical, deterministic, security-engineering-focused approach.
